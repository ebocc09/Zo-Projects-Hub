Publish

Sends the estate to github.com/ebocc09/Zo-Projects-Hub, where every other copy of the Hub can pull it with Check for Updates. What goes is the working tree as it stands, not the last commit — an uncommitted board edit is the normal state here, and publishing a commit would ship something older than what is on screen.

Changes
—
Credential files are refused outright rather than skipped — if one ever reaches the publish set, nothing is sent and it is named here. Machine-local caches and logs are dropped quietly. The token in Sign-ins is what authenticates the push, and it needs Contents: Read and write on this repository.

Store

One file outside every project. Boards read it; only this hub writes it. Delete it and each board falls back to whatever cookie it has of its own — which is nothing, on a machine where only the hub has signed in.
