Teams

Posts a VRI List card to a Teams chat: the cars awaiting receiving inspection that arrived in the last 24 hours. The card carries an Update button that reposts the current list.

In Teams: the chat's ⋯ menu › Workflows › Post to a channel when a webhook request is received. Copy the URL it gives you. Saving a new one mints a new button token, so any card already in the chat stops working — post a fresh one.
Webhook—
Push to a row

Keeps a SharePoint row loaded with the finished card, so the Update button's flow can answer from it without this board being involved. Pushed on the interval below, every time — a row is something to keep right, not a message.

Receives {card, count, site, stamp, vins} — card is the whole Adaptive Card already rendered, as text, for a single multi-line column. It always carries a Submit button, because the flow reading the row waits for one.
With no push URL this reposts to the chat instead, and then only when the cars have changed.
Operating hours

Outside them the board stops scanning, and the row is overwritten once with a card saying the list is not being kept up and when it will be again. Pressing Update out of hours answers with that, rather than with last night's list looking current.
